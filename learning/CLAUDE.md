# Learning workspace

This folder is a `/teach` workspace for learning the skills in this repo. Run `/teach` from here.

The parent `../CLAUDE.md` is the skills repo's maintainer guide. Its rules about buckets, `README.md` entries, `plugin.json`, docs pages and `ask-matt` apply to `../skills/`, not to anything under `learning/`. Its no-em-dash rule still applies here.

- Teaching notes and Nathan's preferences: `NOTES.md`
- Suggested route: `CURRICULUM.md`
- Practice drills: `drills/<name>/BRIEF.md` (learner-facing) and `drills/<name>/ANSWERS.md` (answer key: never reveal before an attempt)
- Primary sources: `../skills/<bucket>/<name>/SKILL.md` and `../docs/<bucket>/<name>.md`
